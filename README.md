# footstep (Android)

걸은 길이 지도에 얇은 선으로 남는 앱. 이 폴더는 **1단계(지도 · 발자취 기록 · 프라이버시 존)**, **2단계 일부(로그인 · 프로필)** 코드와,
이후 단계(친구·채팅·상점·글로벌 지도)를 위한 **Supabase 스키마**와 **한국어 문구 전체**를 담고 있습니다.

> ⚠️ 이 코드는 Flutter/Android 빌드 환경이 없는 곳에서 작성되어 **아직 한 번도 컴파일·실행해 보지 않았습니다.**
> 위치 계산 로직(지오해시·선 단순화·프라이버시 존 분할)은 같은 알고리즘을 별도로 돌려 테스트 기대값을 확인했지만,
> 지도·권한·플러그인 연동은 첫 빌드에서 수정이 필요할 수 있습니다. 빌드 로그를 그대로 알려주세요.

## 구현 범위

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 벡터 지도(흰 배경 + 건물 외곽선), 회전, 현재 위치, 발자취 기록(화면 꺼져도 기록), 오늘 거리, 프라이버시 존(켜기/끄기), 무료 지도 스타일 4종, 로컬 저장 | 코드 작성됨 (미검증) |
| 2-A | 이메일 인증 코드 로그인, 프로필 만들기·수정(사진·닉네임·@태그 중복 확인·상태 메시지), 프로필 탭(총 거리·개인정보 스위치·발자취 초기화·로그아웃·계정 삭제), 하단 탭 | 코드 작성됨 (미검증) |
| 2-B | 친구(@태그 추가·요청·목록), 1:1·그룹 채팅, 그룹 설정, 실시간 메시지·사진 | 스키마·문구만 준비 |
| 3 | 공유 이미지(지도/단색), 상점(지도 스타일·선 모양, 일회성 결제), 세계 지도·지구본, 탐방 메달, 초기화·계정 삭제 UI | 스키마·문구만 준비 |

1단계에서 아직 없는 것: 프라이버시 존을 **길게 눌러 옮기기**(현재는 "현재 위치로 설정"), iOS 빌드, 친구·채팅 화면.

## APK 만들기 (컴퓨터에 Android Studio 없이)

1. GitHub에 새 저장소를 만들고 이 폴더 내용을 그대로 올립니다.
2. 저장소의 **Actions → Android APK → Run workflow** 를 실행합니다.
3. 끝나면 실행 결과 화면 아래 **Artifacts → footstep-apk** 에서 APK를 내려받아 폰에 설치합니다.
   (설치 시 "출처를 알 수 없는 앱" 허용이 필요합니다. 테스트용 서명이라 스토어 배포용이 아닙니다.)

빌드가 실패하면 Actions 로그의 빨간 줄을 복사해서 보내주세요.

로컬에서 빌드하려면(Flutter 설치 후):
```
flutter create --platforms=android --org app.footstep --project-name footstep .
rm -f test/widget_test.dart && python3 tool/patch_android.py
flutter pub get && flutter test && flutter run
```

## 설정값 (`--dart-define`, Actions에서는 Repository secrets)

| 이름 | 용도 |
|---|---|
| `SUPABASE_URL`, `SUPABASE_ANON_KEY` | 로그인·프로필에 사용. Supabase 프로젝트 설정 > API 에서 확인. **비워 두면 서버 없이 지도·기록만 쓰는 개발 모드**로 실행됩니다 |
| `TILES_URL` | 벡터 타일 TileJSON 주소. 기본값은 OpenFreeMap(키 불필요) |

## Supabase 준비

1. supabase.com 에서 프로젝트를 만듭니다.
2. SQL Editor에서 `supabase/migrations/0001_init.sql` 전체를 실행합니다. (PostGIS·citext 확장 포함)
3. Authentication > Providers 에서 Email을 켜고, 이메일 템플릿(Magic Link/Confirm)에 `{{ .Token }}` 인증 코드가 들어가도록 수정합니다. (Google 로그인은 이후 추가)
4. 주요 보안 원칙: 모든 테이블에 RLS 적용 · 채팅방은 친구끼리만 RPC로 생성 · 세계 지도는 지오해시 격자만 업로드하고
   서로 다른 5명 이상·24시간 이후 격자만 공개 · 계정 삭제 함수 포함.

## 지도 데이터와 출처 표기

지도는 OpenStreetMap 데이터를 OpenMapTiles 스키마의 벡터 타일로 받아 앱에서 직접 스타일링합니다(구글 지도 미사용).
화면에 "© OpenStreetMap 기여자 · OpenFreeMap" 표기가 있어야 하며, 사용자가 늘면 타일 호스팅을 자체 구성(PMTiles + CDN)으로 옮기세요.

## 알려진 위험 (첫 빌드에서 확인할 것)

- `maplibre_gl ^0.19.0` 의 API 이름이 설치되는 버전과 다르면 `map_screen.dart` 에서 컴파일 오류가 날 수 있습니다.
- Android 14+ 포그라운드 서비스 권한(`FOREGROUND_SERVICE_LOCATION`)은 패치 스크립트가 추가합니다.
  기기 제조사의 배터리 최적화가 기록을 끊을 수 있어, 실기기 장시간 테스트가 필요합니다.
- 위치 권한은 "앱 사용 중"만 요청합니다. 포그라운드 서비스 알림이 떠 있는 동안 화면이 꺼져도 기록되며,
  "항상 허용(백그라운드 위치)"은 스토어 심사가 까다로워 쓰지 않습니다.
- 발자취는 기기에 원본 좌표로 저장하고, 지도 표시·공유·업로드 시점에 프라이버시 존을 적용합니다.

## 스토어 출시 전 필수

개인정보 처리방침 URL, 위치 수집 공개(Play 데이터 보안 양식), 인앱 계정 삭제(구현 예정: `delete_my_account()`),
위치정보법 신고 검토, 18세 미만 이용 정책.
